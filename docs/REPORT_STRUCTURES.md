# Канон структур отчетов

**Статус:** активен  
**Источник:** `backend/app/reporting/section_templates.py`

Документ фиксирует каноническую структуру всех типов отчетов, которые генерирует движок.
Любые изменения шаблонов должны соответствовать этой структуре, чтобы сохранить совместимость фронта и логику данных.

---

## 1. Натальная карта
**Код:** `natal_master`
**Фокус:** Глубокий анализ личности, сильные стороны, риски и стратегия.

| ID секции | Заголовок | Фокус |
| :--- | :--- | :--- |
| `executive_summary` | Главное | 5-7 пунктов: сильные стороны, риски, ключ к отношениям/деньгам, фокус развития. |
| `input_frame` | 1. Данные рождения | Технические данные: дата, время, место, таблица планет. |
| `synthesis` | 2. Синтез (метафора и ядро) | Метафора личности + главный тезис. |
| `framework_elements_modes` | 3. Каркас (стихии и модальности) | Баланс стихий, доминанта, дефицит, стиль жизни. |
| `axes_truths` | 4. Оси (две правды) | ASC-DSC (личное/партнер), IC-MC (дом/карьера), 2-8 (ресурсы), 3-9 (мышление). |
| `aspects_beginner` | 5. Аспекты для новичка | 4-6 точных аспектов: якорь, сценарий, ресурс, тень, ключ. |
| `configurations_geometry` | 6. Конфигурации (геометрия) | Конфигурации (тау-квадрат, большой тригон и т.п.). |
| `dispositor_office` | 7. Диспозиторная логика | Иерархия диспозиторов (метафора офиса). Главная планета. |
| `core_triad` | 8. Личное ядро | Солнце, Луна и Асцендент. |
| `mercury_mind` | 9. Мышление (☿ Меркурий) | Стиль мышления и ментальные ловушки. |
| `shadow_trauma` | 10. Тень и травма | Хирон и Лилит: якорь, тень, ключ. |
| `nodes_growth` | 11. Узлы (вектор взросления) | Южный/Северный узлы: прошлое/рост. |
| `vertex_fate` | 12. Вертекс | Встречи и уроки. |
| `balance_wheel` | 13. Колесо баланса | Все 12 домов: тема, плюс, минус, вектор. |
| `love_intimacy` | 14. Любовь и близость | Венера и Марс. |
| `money_realization` | 15. Деньги и реализация | Дома 2/6/10 + Юпитер/Сатурн. |
| `stars_transuranus` | 16. Звезды и Трансураны | Уран/Нептун/Плутон: режимы и влияние. |
| `time_cycles` | 17. Время и циклы | Соляр и циклы. |
| `final_synthesis` | 18. Финальная сборка | Итог, девиз, главный совет. |
| `technical_appendix` | Приложение | Сырые технические данные (генерируется программно). |

## 2. Альманах года
**Код:** `year_forecast`
**Фокус:** Стратегическое планирование на 12 месяцев.

| ID секции | Заголовок | Фокус |
| :--- | :--- | :--- |
| `year_meta` | 0. Метафора года | Метафора и девиз года на основе медленных транзитов/соляра. |
| `month_1_forecast` | 1. Месяц 1 | Детальный разбор: статус, активаторы, события, стратегия. |
| `month_2_forecast` | 2. Месяц 2 | ... (та же структура для всех 12 месяцев) |
| ... | ... | ... |
| `month_12_forecast` | 12. Месяц 12 | ... |

**Структура на месяц:**
1. Метаданные (период, локация)
2. Статус (светофор)
3. Центральная нить
4. Активаторы (аспекты)
5. Карта сфер
6. Событийный слой
7. Личный слой
8. Глубинный слой
9. Солярный контекст
10. Тайм-лорды
11. Фиксированные звезды
12. Трансураны
13. Итог месяца

---

## 3. Прогноз на месяц
**Код:** `month_forecast`
**Фокус:** Тактический план на текущий/следующий месяц.

| ID секции | Заголовок | Фокус |
| :--- | :--- | :--- |
| `month_full_forecast` | Прогноз на месяц | Монолитный блок: статус, ключевые события, 4 недели, итог. |

**Внутренняя структура:**
1. Статус (метафора, фон, рычаг).
2. Ключевые события (3-5 дат).
3. Стратегия по неделям (4 блока: фокус, риск, ресурс).
4. Итог (финансы, отношения, энергия).
5. Рекомендации.

---

## 4. Стратегия недели
**Код:** `week_forecast`
**Фокус:** Практические рекомендации на 7 дней.

| ID секции | Заголовок | Фокус |
| :--- | :--- | :--- |
| `week_strategy` | Стратегия недели | Монолитный блок: тема, статус, подневная стратегия (7 дней), итог. |

**Внутренняя структура:**
1. Главная тема (метафора).
2. Статус (светофор).
3. Подневная стратегия (день + свет + астро-фактор + ощущения + риск + стратегия).
4. Итог по сферам (финансы, энергия, отношения, магия).

## 5. Хорарный вопрос
**Код:** `horary_answer`
**Фокус:** Бинарный ответ «Да/Нет» на конкретный вопрос.

| ID секции | Заголовок | Фокус |
| :--- | :--- | :--- |
| `horary_00_passport` | 0. Паспорт вопроса | Вопрос, дата, время, место (программно). |
| `horary_00_technical` | Данные карты | Роли, пригодность карты (программно). |
| `horary_01_verdict` | 1. Ответ сразу | Вердикт (✅/❌), причина, срок, риск. |
| `horary_02_radicality` | 2. Пригодность карты | Флаги радикальности (ASC, Луна, Сатурн) + уровень уверенности. |
| `horary_03_significators` | 3. Сигнификаторы | Роли: кверент, квестит, оппонент. |
| `horary_04_state` | 4. Состояние сторон | Таблица силы планет (эссенциальная/акцидентальная). |
| `horary_05_mechanics` | 5. Механика исхода | Аспекты: приложится/расходится, рецепция, запрет и т.п. |
| `horary_06_moon` | 6. Луна как сценарий | Движение Луны (прошлое -> будущее). |
| `horary_07_timing` | 7. Тайминг | Оценка временного окна. |
| `horary_08_conditions` | 8. Условия успеха | Условия для ответа «Да». |
| `horary_09_risks` | 9. Риски и ограничения | Скрытые риски. |
| `horary_10_alternatives` | 10. Альтернативы | План Б, если ответ «Нет». |
| `horary_11_summary` | 11. Итог | Итог: ответ, причина, срок, риск. |
