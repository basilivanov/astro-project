## CI / Cron Checklist

1. **Baseline before any slice regression run**: `docker exec astro-project-backend-1 python3 scripts/pipeline.py` must be green (shared requirement from `docs/GRACE_ARTIFACTS.md`).
2. **`M-NATAL-SUMMARY-LAYER` PRs**: execute every pytest listed plus the forecast read E2Es; finish with `python3 scripts/live_quality_benchmark.py --manifest docs/benchmark_manifests/natal_rerun_2026-03-19.json` and attach benchmark log to the Gate 3 note.
3. **`FEED-PERSONALIZED-DAILY` PRs**: run backend targeted pytest trio + `core-ux` Playwright job (with health probes). Keep `feed_admin_watch` cron enabled every 15 minutes to alert on `feed.error` or stale success windows.
4. **`ADMIN-ENTITLEMENTS-FLOW` PRs**: run entitlement pytest bundle + admin Playwright suite; replay latest admin logs via `tools/admin_logs/replay_last.py` and archive outputs with rollout evidence. The same 15‑minute `feed_admin_watch` cron covers admin telemetry.
5. **`FORECAST-LADDER-CATALOG-FLIP` PRs**: execute billing/access pytest list, storefront/create/history E2Es, and the `E2E_ENABLE_ONE_OFF_RUNTIME=1` billing-mock cases. Keep the `forecast-catalog-watch` cron job active (default 15-minute cadence) so that catalog checkout/resume errors trigger alerts.
6. **Monitoring integration**: both watcher scripts exit with non-zero status on alerts, so wire them into CI/CD health gates or Prometheus checks to block deploys when flows degrade.
7. **Env check auto-heal**: always run `gracectl env check` (see `docs/gracectl.md`) before slice verification; env check will curl `/reports` via `astro-project-frontend_dev-1`. When the probe returns `404` or times out, the command issues `docker restart astro-project-frontend_dev-1` and re-runs the health check so Playwright suites inherit a clean frontend container.
